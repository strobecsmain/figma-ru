# Как это устроено

Патч состоит из двух независимых частей и одной программы, которая их ставит.

- **Оболочка** — меню, диалоги, панель вкладок. Figma локализует их сама, поэтому
  это настоящий перевод: в архив приложения добавляется `i18n/ru.json`, а код
  правится так, чтобы он его выбрал.
- **Редактор** — панели, тулбар, файловый браузер. Эти строки приходят с
  `figma.com`, русской сборки у Figma нет, поэтому они переводятся прямо в DOM
  слоем, который дописывается в preload веб-вида.

Части ставятся независимо: если в новой версии Figma код оболочки изменится,
слой редактора всё равно встанет, а установщик скажет, какая половина не
применилась.

## Три ограничения Figma

Все три выяснены опытным путём и проявляются одинаково: приложение доходит до
исполнения `main.js`, печатает первую строку лога и молча завершается — ни
ошибки, ни диалога, ни записи в журнале Windows. Из-за этого их легко перепутать
друг с другом.

**1. Язык оболочки диктует веб-приложение.** Все решения о локали проходят через
одну функцию. К ней ведут три пути: локаль ОС при старте, поля `locale`/`locales`
из `settings.json` и — решающий — IPC-сообщение `setLocales`, которое
веб-приложение присылает, узнав язык аккаунта. Поэтому положить словарь рядом с
готовыми и поменять настройку бесполезно: как только веб-приложение сообщит `en`,
оболочка вернётся к английскому. Патч фиксирует саму функцию, закрывая все три
пути разом. Ищется она **по форме кода, а не по имени**: идентификаторы
минифицированы и меняются со сборками (`X_` в 126.9.6, `tR` в 126.9.1).

**2. У архива есть хвост.** `app.asar` заканчивается восемью байтами, которые не
принадлежат ни одной записи. Пересборка без них не запускается.

**3. Размер архива зафиксирован.** Figma проверяет длину `app.asar` при старте.
Архив с верным содержимым, верными integrity-хешами, верным заголовком и
сохранённым хвостом всё равно не запустится, если размер отличается хотя бы на
несколько байт — проверено добавлением 64 пробелов в нетронутую пересборку.

Отсюда весь бюджет патча. Место освобождается так: японский словарь удаляется,
освобождая место под русский, остальные шесть сжимаются (Figma поставляет их с
отступами). Остаток добивается пробелами в конце `ru.json`; подгон итерационный,
потому что длина заголовка сама зависит от размеров файлов. Если места всё равно
не хватит, установщик жертвует ещё одним языком и говорит каким.

## Порядок и защиты

1. Проверить, что архив — оригинальный, и сохранить копию рядом.
2. Собрать новый архив целиком в памяти.
3. Проверить собранное: точный размер, хвост, границы всех записей, разбор
   `ru.json`, наличие патча локали и слоя редактора.
4. Записать во временный файл рядом с целью и **переименовать** поверх — на том
   же томе это либо происходит целиком, либо не происходит вовсе.

Проверка «оригинальности» опирается только на следы, которые оставляет сам патч
(`ru.json`, маркер слоя, закреплённая локаль), и **никогда** на то, совпала ли
форма кода. Это разные вопросы: сборка Figma с непривычной формой кода —
нетронутая, и отвергать её здесь значило бы сорвать всю установку, включая слой
редактора, который от этого кода не зависит.

Копия оригинала тоже проверяется перед восстановлением: скопировать обрезанный
или уже пропатченный файл поверх рабочего — тот же молчаливый отказ запускаться.

## Слой для редактора

Preload веб-вида работает в песочнице (`sandbox: true`, `contextIsolation: true`,
`nodeIntegration: false`) — ни `fs`, ни `require` соседних файлов, — но доступ к
DOM у него есть, а больше ничего и не нужно. Поэтому словарь встраивается прямо в
код слоя, и самодостаточный скрипт дописывается в конец preload.

Правила безопасности, по убыванию важности:

1. Замена только когда **всё** содержимое текстового узла совпало с известной
   фразой. Никаких замен по подстроке.
2. Не трогать то, что пользователь редактирует: дочерний узел `<textarea>` — это
   и есть его значение, а `contenteditable` — живой ввод.
3. Никогда не бросать исключения: любая ошибка внутри слоя оставляет приложение
   ровно таким, каким оно было.

Слой работает только на доменах Figma: preload подключён и к страницам входа
через сторонние сервисы, и там ему делать нечего. Выключается без удаления
патча: `localStorage.setItem('figma-ru:off','1')` в консоли веб-приложения.

**Что под риском, а что нет.** Текст на холсте рисуется в `<canvas>` и в DOM не
попадает, так что содержимое макета недостижимо по построению. В DOM есть имена
слоёв, страниц, стилей и файлов, и они переводятся, если имя точно совпадает с
ключом словаря. Автоматические имена Figma нумерованы (`Frame 22340`) и под это
не попадают. Ущерб ограничен: эффект чисто визуальный — проверено на поле
переименования файла, которое подставляет `Untitled` из модели Figma, а не «Без
названия» из DOM.

## Сборка

```powershell
.\build.ps1
```

Готовит встраиваемые ресурсы (Node) и компилирует `dist\Figma на русском.exe`
компилятором C#, который входит в состав Windows (.NET Framework). Пользователю
ни Node, ни .NET SDK не нужны — WPF и рантайм уже есть в системе.

## Расширение словаря редактора

Слой умеет собирать строки, которые встретил, но не смог перевести. В консоли
веб-приложения (меню → «Диагностика» → «Инструменты разработчика веб-приложения»):

```js
localStorage.setItem('figma-ru:collect', '1')          // включить, затем перезагрузить вкладку
JSON.parse(localStorage.getItem('figma-ru:missing'))   // посмотреть собранное
```

**Собранный список может содержать имена из ваших файлов** — просмотрите его,
прежде чем куда-то отправлять.

Сборщик проверяет словарь: дубликаты ключей (`JSON.parse` молча оставил бы только
последний), переводы, совпадающие с ключами (движок переписывал бы их
бесконечно), и ключи, различающиеся только типографикой.

## Что где лежит

```
src/exe/            установщик: WPF-окно и движок asar на C#
  Json.cs           разбор и сборка JSON с сохранением порядка ключей
  Asar.cs           чтение и пересборка app.asar, включая хвост
  Patcher.cs        поиск установок, бюджет, подгон размера, проверки
  App.cs / Xaml.cs  окно
src/i18n/ru.json    словарь оболочки: 328 строк
src/web/            слой редактора: движок, словарь, chrome-only список
tools/              то же самое на Node — эталонная реализация и сборка ресурсов
build.ps1           сборка exe
```

`tools/` — рабочая реализация на Node, с которой патч разрабатывался; C# — её
порт. Обе делают одно и то же, и `install.js` остаётся удобным способом
проверить изменения без пересборки exe.

Проверено на Figma Beta 126.9.6 и 126.9.1, и на копии установки, оформленной как
стабильная ветка.
