Figma на русском

Меню, диалоги, панель свойств и тулбар — на русском. Одна программа, ставится в два клика, откат в один.

Скачать для Windows
Стабильная Figma и Figma Beta · бесплатно и с открытым кодом

Установка

Ничего дополнительно ставить не нужно.

  1. Скачайте программуФайл FigmaRu-Setup.exe со страницы релизов.
  2. Закройте FigmaЗначок Figma Agent в трее закрывать не нужно.
  3. Запустите и нажмите «Установить русский»Через несколько секунд открывайте Figma.

Меню целиком

Figma локализует меню сама — патч добавляет русский в её собственную систему перевода.

Что переводится

Безопасно и обратимо

Чтобы не пришлось верить на слово.

Откат в один клик

Рядом сохраняется копия оригинала. Кнопка «Вернуть английский» возвращает всё как было.

Только файлы Figma

Меняется один файл app.asar внутри папки Figma. Больше ничего.

Без интернета

Программа ничего не скачивает и никуда не отправляет. Всё нужное уже внутри.

Проверка до замены

Новый файл сначала собирается и проверяется целиком. Не прошёл — Figma остаётся нетронутой.

Без прав администратора

Figma живёт в вашей папке. Запускать «от имени администратора» не нужно и вредно.

Открытый код

Весь код на GitHub, включая словари. Можно прочитать и собрать самому.

После обновления Figma перевод пропадает. Figma ставит каждое обновление в новую папку. Запустите программу ещё раз и снова нажмите «Установить русский» — она сама заметит обновление.

Windows может предупредить о неизвестном издателе. У проекта нет платной подписи разработчика. Нажмите «Подробнее» → «Выполнить в любом случае».
